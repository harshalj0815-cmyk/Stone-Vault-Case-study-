Encrypt before the Drive sees it

Stone Vault encrypts your files on this computer before they reach Google Drive.
Drive only stores scrambled data. You unlock and open them here.

Problem

Storing passports, tax returns, or client contracts in Google Drive still leaves readable files and readable names with the provider. Cloud-held data has been breached before, and companies have used customer data in ways people did not expect. What feels safe today is not a fixed promise.

Solution

Stone Vault is an on-device encryption gateway. You upload, retrieve, download, or view files through the gateway. Files stay encrypted in Drive as scrambled .lkdv blobs with random names, and only decrypt on the gateway. The passphrase never leaves this machine.

Specs

        
    
          
  • 
            
    
              
              Strongest encryption
            
    
            Each file is locked with AES-256-GCM. Keys come from your passphrase through Argon2id with a unique salt, so the same passphrase still produces different keys per vault.
          
    • 
          
  • 
            
    
              
              Single channel access
            
    
            Files can only be opened through Stone Vault on a machine that has the passphrase. Drive alone is not enough to read them.
          
    • 
          
  • 
            
    
              
              User friendly interface
            
    
            The UI stays close to a normal Drive-style vault, so a new user can upload, browse, and open files without learning a new system.
          
    • 
          
  • 
            
    
              
              Existing cloud
            
    
            You keep Google Drive for storage and sync. Stone Vault adds the encryption layer on top, so there is no need to switch clouds.
